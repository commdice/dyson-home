# Decisions

What was decided, when, and why. Record a decision when it was made so the
reasoning isn't lost. Add new entries at the top. If a later decision replaces
an earlier one, add the new entry and mark the old one **Superseded**.

## Entry format

```
## YYYY-MM-DD — Short title
- **Context:** what prompted the decision
- **Decision:** what was chosen
- **Why:** the reasons
- **Alternatives considered:** what else was on the table
- **Status:** Active | Superseded by <date — title>
```
